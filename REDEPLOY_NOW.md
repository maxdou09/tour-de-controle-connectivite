# ⚡ REDÉPLOYER MAINTENANT (10 min)

## 3 Étapes Simples

### ÉTAPE 1 : Token GitHub (1 min)
```
Allez sur : https://github.com/settings/tokens/new
→ Générez un token avec "repo"
→ Copiez le token
```

### ÉTAPE 2 : Exécuter le Script (1 min)
```powershell
cd "c:\...\tour-de-controle-connectivite"
.\REDEPLOY_COMPLETE.ps1
```

Répondez aux questions :
- Token GitHub (collez)
- Username GitHub
- Nom du repo (appuyez Entrée)

### ÉTAPE 3 : Créer le Repo GitHub (5 min)
```
1. Allez sur https://github.com/new
2. Nommez : tour-de-controle-connectivite
3. Laissez Public ✅
4. NE cochez PAS : Initialize repository
5. Cliquez Create
6. Revenez au PowerShell → Appuyez Entrée
```

---
